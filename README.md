# 教研联盟管理平台

教研联盟管理平台的独立项目仓库，用于持续管理产品需求、源代码和开发记录。

GitHub 公开仓库：[XOxiaosi/teaching-research-alliance](https://github.com/XOxiaosi/teaching-research-alliance)。

## 当前状态

当前需求为V1.23，已建立 TypeScript monorepo、权限/接口契约、金额基础库和首批服务层。PostgreSQL 周费与分润同事务保存、受影响双方整月重算、分配快照、幂等和版本冲突及异步 HTTP 数据库适配，已通过本地合成数据库及回环 HTTP 集成验证。个人余额/当前财年课时分润、正常场地目录已接通数据库读取；注册/重置/登录限流、教师个别费率、退款、完整财务和看板业务仍在开发。微信小程序、手机和电脑网页要求同等业务；开发者最高维护权限、普通业务角色、业务身份与资金账户分别管理。

开发者本人拥有最高权限，可访问源码及全部数据，并设置管理员；管理员可调整全体成员身份、费率及全部业务数据，财务/校长等按获授范围操作。修改保留记录，身份展示名更正不改变账户编号或转移余额。

REQ-024将动态正负浮动作用于转介绍池，不再新分给联盟。基础规划介绍10%遇−2个百分点时实际池8%，有导师按8:2分为6.4%/1.6%；教师基础12%同样按动态调整。当前动态档位为：最低档−2%至最高档+4.5%，不设16%上限。校区与平台管理费保持自身比例；校区2%给介绍方学业规划自身校区，分配前F总营收按授课方校区统计，不重复入账。

场地由教师创建，自用免收、他用默认5%进入独立场地账户。发起者可设置受邀老师查看及提现权限，仅可提对应场地余额。共享看板显示老师/学生、每老师周场地费、总使用费及成员权限。改场地从当周重算，暑期中途变更上报管理员处理。

学业规划导师可增加/移除自己名下规划师管理关系，从调整当周起重算、更早周不变；可查看旗下与本人直接介绍学生的课时费、授课老师、介绍费及比例。该权力不包含改比例、删账号或查看无关个人余额/工资。

学生退款由授课老师选一笔或多笔周费用、填写原因提交，总部财务批准后全额冲回所选笔全部有效分润；现金退付在线下，不再记系统付款。退款审批当次只冲原笔；之后新增/改错按排除已退款的接收及推荐金额重新计算净额，未退款费用可在正常整月计算中调整，已退款不复活。提现仍足额提交即扣豆且不可改撤，财务线下转账；场地与个人分账，财务撤回返原账户一次。

工资只在总部财务界面设置和确认现金发放后的个人扣豆；奖金职务账户到个人，社保公积金按财务设置日期生待办、确认后扣财务职务账户。全部比例仅管理员可改；普通周组长从调整当周起，其他人员调整按PRODUCT权限。原始来源、历史账务及每周完整Excel/附件永久备份保留。

财务本人采买从个人页面提交到财务业务账户，自动通过并直接划转：财务业务账户扣豆、申请人个人账户加豆，同一申请只执行一次。所有人的财务申请必须对应单据及申请截图，自动通过不免除留存。

最终规则只在PRODUCT维护。分区财务仅看辖区教师个人余额与收入汇总；其他关系与寒假中途变更由管理员指定范围并预览；授课可选全部正常使用中的场地，选用不授予看板或提现权限。当前推进首条真实数据库业务闭环，实施任务见开发计划；密码登录和会话已接通PostgreSQL并验证撤销失效，网页已有首批教师登录、余额、学生选择和周费登记页面，小程序尚未接入业务页面，工程检查不代表用户验收或上线完成。

## 本地开发

```sh
npm install
npm run check
npm run db:check
```

当前检查使用合成数据；集成测试为每个场景创建独立 schema 并从空执行全部迁移，结束只清理自身 schema。扩展统一安装在 public 并使用数据库锁避免并行初始化竞争；日常本地库仍按原迁移状态保留。第六个迁移新增费率政策、结算运行和不可变分配快照；旧费用不会自动回填已入账状态，非空业务库升级必须先核对和重建结算基线。备份恢复演练和生产数据库仍未完成。

使用隔离合成数据库验证结算（先构建，再从环境注入连接串）：

```sh
npm run build
DATABASE_URL=你的本地合成库连接串 npm run test:postgres --workspace @teaching-research-alliance/api
```

## Git 管理

默认分支为 `main`。后续功能开发使用独立分支，提交前检查变更并进行与变更相应的验证。

GitHub 同步通过提交和推送完成；本地文件修改不会自动上传。配置远端后可使用：

```sh
git status
git add <本次修改的文件>
git commit -m "说明本次变更"
git push
```

### 本地合成网页演示

先启动本地PostgreSQL，显式设置本机合成库的 `DATABASE_URL`（连接示例见本地Docker配置），在项目根运行：

```sh
npm run dev:demo
```

该命令新建随机隔离schema并初始化演示数据，固定业务时钟为北京时间2026-09-21 12:00，只监听本机3100端口；正常退出时仅清理本次schema。异常强制终止可能遗留演示schema，不修改日常public业务数据。另开终端运行 `npm run dev:web`，浏览器访问命令显示的本地地址。

演示授课账号 `13800000001`、规划师账号 `13800000002`，合成密码 `Local-demo-only-2026`；这些仅用于临时演示。授课老师选学生登记1000豆时余额720豆，改同笔为1200豆后余额864豆。页面刷新需重新登录；“退出此页面”仅清本地会话，不等于服务器注销。该演示没有真实支付、注册或生产接入。

网页使用[React createRoot](https://react.dev/reference/react-dom/client/createRoot)和[Vite](https://vite.dev/guide/)，生产构建检查为 `npm run build:web`。此演示尚未完成推荐创建、接收时场地关系、小程序及完整财务流程。
