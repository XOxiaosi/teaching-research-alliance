# 教研联盟管理平台

教研联盟管理平台的独立项目仓库，用于持续管理产品需求、源代码和开发记录。

GitHub 私有仓库：[XOxiaosi/teaching-research-alliance](https://github.com/XOxiaosi/teaching-research-alliance)。

## 当前状态

当前需求为V1.15，尚无业务代码。微信小程序、手机和电脑网页同等业务；三类登录权限、分润身份和资金账户分开记录。普通注册及管理员分配权限、实时月度/当前财年规则重算、跨年保留余额、完整Excel与原件永久备份的要求保留。

工资名单、计划及扣豆设置集中总部财务界面，个人教师页无工资数据，余额仍包含已确认的现金工资扣减。组织为总部—分区—校区；分区财务是有自身分润和区内人员安排能力的职责，按其他职责相同方式切换进入，展示自身收入、下属校区收入和分区营收汇总，不自动取得总部财务办理权。各项分配初值仍由管理员维护，校区与个人账务分开，汇总不重复入账。

尚待落实D24其他角色业务账户与个人余额的关系、D25立即提现的余额及到账边界、D26医社保公积金方向和调度、D27咨询费Q初始默认值、D28职务负责人可调部分的范围。详细问题只在PRODUCT维护；受影响旧方案不作为本轮最终实现/验收依据。当前仍为文档澄清，未接入真实数据、银行支付或部署资源。

## Git 管理

默认分支为 `main`。后续功能开发使用独立分支，提交前检查变更并进行与变更相应的验证。

GitHub 同步通过提交和推送完成；本地文件修改不会自动上传。配置远端后可使用：

```sh
git status
git add <本次修改的文件>
git commit -m "说明本次变更"
git push
```

## 数据边界

仓库用于代码、文档和脱敏示例。真实学校、教师、学生资料、上传文件、数据库、密钥和本地环境配置不进入版本控制。
