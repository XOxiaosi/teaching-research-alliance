教研联盟管理平台的独立项目仓库，用于持续管理产品需求、源代码和开发记录。

GitHub 私有仓库：[XOxiaosi/teaching-research-alliance](https://github.com/XOxiaosi/teaching-research-alliance)。

## 当前状态

当前需求为V1.13，尚无业务代码。微信小程序、手机和电脑网页同等业务；三类登录权限、分润身份和资金账户分开记录。普通注册及管理员分配权限、实时月度/当前财年规则重算、跨年保留余额、完整Excel与原件永久备份的要求保留。

本轮明确报销为审批后财务执行的内部欢乐豆划拨，与线下支付无关；工资和奖金由发起账户扣、收款账户加，立即生效，撤销按原笔双侧反向处理。换校区或组长不追算变更前月份；旧财年错误由老师口头告知财务，财务更正后以差额改变当前累计余额；比例字段仅系统管理员调整。

尚待决定D24角色账户与统一个人余额的关系、D25立即提现的余额及到账边界、D26医社保公积金划拨方向和月度调度。详细问题只在PRODUCT维护；受影响旧方案不作为本轮最终实现/验收依据。当前仍为文档澄清，未接入真实数据、银行支付或部署资源。

## Git 管理

默认分支为 `main`。后续功能开发使用独立分支，提交前检查变更并进行与变更相应的验证。

GitHub 同步通过提交和推送完成；本地文件修改不会自动上传。配置远端后可使用：

```sh
git status
git add <本次修改的文件>
git commit -m "说明本次变更"
git push
```

## 数据边界

仓库用于代码、文档和脱敏示例。真实学校、教师、学生资料、上传文件、数据库、密钥和本地环境配置不进入版本控制。
