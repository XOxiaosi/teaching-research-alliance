教研联盟管理平台的独立项目仓库，用于持续管理产品需求、源代码和开发记录。

GitHub 私有仓库：[XOxiaosi/teaching-research-alliance](https://github.com/XOxiaosi/teaching-research-alliance)。

## 当前状态

当前需求为V1.11：微信小程序与手机/电脑网页具备同等业务能力；采用个人/公司账户、三类权限和按身份分列的欢乐豆结算。已明确实时月度及全财年重算、9月至次年8月的财年、每周五10点自动Excel与凭证原件备份，文件及历史数据永久保留（不含导入）。提现提交即扣款自动通过，提交后仅财务可撤回；财务人工调账填写原因、提交即生效并送系统管理员审批；管理员与授权开发者免审调账但完整留痕，上级可查阅调整明细，需审批的调整被拒绝或退回时自动冲回；审批前增加的余额也可提现。学生按老师/课程独立建档，支持复用资料再推送、每周累计记录；财务可设置月度工资计划并选择单月或往后调整；工资走账在线下发放后确认扣除欢乐豆，与奖金收入分开。错误分润无法提交；历史项目用当时名称；敏感字段按职责完整显示或脱敏，导出仍仅系统管理员。收支报表分年统计、余额跨年保留；每月1日北京时间00:00生成工资待办，生成不扣豆。用户集中答复和补充确认已归档，本轮待确认事项已全部收口。当前只有需求与技术文档，尚无业务实现。

## Git 管理

默认分支为 `main`。后续功能开发使用独立分支，提交前检查变更并进行与变更相应的验证。

GitHub 同步通过提交和推送完成；本地文件修改不会自动上传。配置远端后可使用：

```sh
git status
git add <本次修改的文件>
git commit -m "说明本次变更"
git push
```

## 数据边界

仓库用于代码、文档和脱敏示例。真实学校、教师、学生资料、上传文件、数据库、密钥和本地环境配置不进入版本控制。
