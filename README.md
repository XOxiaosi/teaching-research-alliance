# 教研联盟管理平台

教研联盟管理平台的独立项目仓库，用于持续管理产品需求、源代码和开发记录。

GitHub 私有仓库：[XOxiaosi/teaching-research-alliance](https://github.com/XOxiaosi/teaching-research-alliance)。

## 当前状态

当前需求为V1.20，尚无业务代码。微信小程序、手机和电脑网页同等业务；三类登录权限、分润身份和资金账户分开记录。普通注册及管理员分配权限、实时月度/当前财年规则重算、跨年保留余额、完整Excel与原件永久备份的要求保留。

工资名单、计划及扣豆设置集中总部财务界面，个人教师页无工资数据，余额仍包含已确认的现金工资扣减。组织为总部—分区—校区；分区财务是有自身分润和区内人员名单查看能力的职责；调校区、换组长、换导师等人员调整由管理员操作，按其他职责相同方式切换进入，展示自身收入、下属校区收入和分区营收汇总，不自动取得总部财务办理权。所有分配比例仅管理员可改；运营校长、分区财务、场地运营、教研组长只查看自身职责对应比例。D28已关闭。校区与个人账务分开，汇总不重复入账。

学业规划是专门招生且不教学的个人身份，介绍费初始10%、校区管理费2%；教师介绍费初始12%、校区管理费0，比例均由管理员维护。动态浮动独立归联盟总收款，负向和旧上限映射待定。校区总营收取分润前课时费F，管理费单列；组长从变更当周起重算，退款只冲回该笔有效净分配并标已退款。费用统计替代课时统计，校长/组长/教学指导导师可在授权人员范围查看学生、费用、余额及非工资收入，工资及比例限制保留。财务个人报销可切财务视角自审。

各身份个人所得统一归本人个人账户，职务业务资金独立；奖金从职务账户到个人。提现足额提交立即通过扣豆，用户不可修改或撤回，超额提示“超出可用金额”；银行卡交互在系统之外，财务转账后标完成不再次扣款，完成前可手动撤回一次返豆。医社保、公积金由财务职务账户承担，财务设置每月日期，到期生成待办、确认后扣豆。咨询平台费即上述2%校区管理费，只收一次，由授课老师承担给校区；教师介绍为0。

场地由教师创建、可分享只读看板；他人场地默认5%进入独立场地账户，自有场地免收；所有者及获其明确授权的受邀老师可按该场地余额提现。接受学生时选择场地，修改从当周重算，更早周不变，他用/自用切换同步调整场地费与授课个人剩余。学业规划导师管理规划师，旗下介绍费池10%拆为规划师8%和导师2%；无导师关系仍10%，导师本人介绍10%，不与教学指导导师7%混用。

D24–D27及D33已关闭；学业规划校区2%归介绍方学业规划自身所在校区，与授课方校区总营收分别统计。尚待D30联盟负向/封顶、D32其他关系和假期中途变更、D34退款和财务查看/自审细节、D35场地共享字段及选用范围、D36规划导师管理范围及关系生效时间；详细问题只在PRODUCT维护。当前为文档澄清，未接入真实数据、银行支付或部署资源。

## Git 管理

默认分支为 `main`。后续功能开发使用独立分支，提交前检查变更并进行与变更相应的验证。

GitHub 同步通过提交和推送完成；本地文件修改不会自动上传。配置远端后可使用：

```sh
git status
git add <本次修改的文件>
git commit -m "说明本次变更"
git push
```

## 数据边界

仓库用于代码、文档和脱敏示例。真实学校、教师、学生资料、上传文件、数据库、密钥和本地环境配置不进入版本控制。
