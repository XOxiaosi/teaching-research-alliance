# DEV-001｜接口与权限契约

本文件是开发阶段的接口入口约定。最终业务规则以 [PRODUCT](../../PRODUCT.md) 为准；机器可读的动作、职责、端点和错误码在 `packages/contracts/src/index.ts`。客户端只能使用当前角色上下文返回的能力，金额、角色和数据范围由服务端重新校验。

## 角色上下文

一个自然人只有一个登录账号和个人账户。登录后服务端返回可切换的角色上下文；切换上下文不会合并多个职责的权限。

| 上下文 | 可见或可做的最小范围 | 明确禁止 |
|---|---|---|
| `SYSTEM_OWNER` | 全部数据和系统维护；授予/撤销管理员 | 不能把源码维护能力隐式下放给管理员 |
| `SYSTEM_ADMIN` | 全员身份、费率、关系、业务数据、完整导出 | 不能授予或撤销 `SYSTEM_OWNER` |
| `TEACHING_TEACHER` | 本人当前财年、推荐/接收、周费用、个人提现、自建场地 | 不能改费率、人员关系或他人账户 |
| `ACADEMIC_PLANNER` | 对外推荐及本人介绍链数据 | 不承担授课接收，不因招生身份获取管理权限 |
| `HEADQUARTERS_FINANCE` | 总部财务单据、工资、扣费和全局财务业务 | 不替普通老师发起个人提现；不把工资字段返回个人页 |
| `REGION_FINANCE` | 本区名单、校区营收、分区营收、辖区教师个人余额与收入汇总 | 不看逐笔个人结算、工资、他人比例；不能导出或改人员关系 |
| `CAMPUS_PRINCIPAL` | 所属校区学生、费用、教师余额和非工资收入 | 不能改人员关系或比例 |
| `GROUP_LEADER` | 关联教师的学生、逐笔费用、余额和非工资收入 | 不能改比例或跨关联范围查询 |
| `TEACHING_MENTOR` | 指导对象的学生、逐笔费用、余额和非工资收入 | 不能改比例或查看工资 |
| `PLANNING_MENTOR` | 自己名下规划师关系及介绍链费用/比例 | 不能改比例、删账号或读取团队余额/工资 |
| `VENUE_OWNER` | 自有场地看板、共享授权和该场地提现 | 不取得公司职务、费率配置或其他场地权限 |

`VIEW_SHARED_VENUE_BOARD` 和 `WITHDRAW_FROM_SHARED_VENUE` 必须分别检查。授课老师选择全部正常使用中的场地是业务输入权限，不等于获得该场地共享看板或提现权。

## 写入约定

- 每个写请求带 `requestId`；资金相关写请求还带客户端生成的 `idempotencyKey`。服务端以请求身份、当前角色上下文、数据范围和版本号重新校验。
- 修改带 `expectedVersion`。版本冲突返回 `VERSION_CONFLICT`，客户端重新读取后由用户决定是否重试，不覆盖他人结果。
- 周费用、关系变更、费率配置和财务业务都先预检，再在一个数据库事务中发布原始版本、计算版本和账务差额；失败不产生半笔有效账务。
- 关系变更（调校区、换教学指导导师等）及寒假中途变更必须先由管理员提交影响预览，再提交明确生效范围；预览输入变化后必须重新预览。
- API 返回 `contractVersion` 和服务器计算版本；客户端不能把旧余额当成本次写入已完成。

## 首批端点

端点的 `method/path/action/responseVersion` 由 `ENDPOINT_CONTRACTS` 导出，后端实现不得自行改名。首批端点包括：会话和角色切换、推荐/接收、周费用、个人提现、财务单据、分区个人汇总、管理员费率预览、关系预览/发布、场地创建/可选目录和完整备份任务。

分区个人汇总端点只返回：教师稳定标识、展示名、当前个人余额、收入汇总、期间和计算版本。不得返回逐笔分配、工资、银行卡或团队比例；导出权限仍单独判断。

## 错误码

客户端按错误码展示稳定提示，不能根据 SQL 错误或后端异常文本猜测业务状态：

`UNAUTHENTICATED`、`FORBIDDEN_SCOPE`、`ROLE_CONTEXT_REQUIRED`、`INVALID_INPUT`、`VERSION_CONFLICT`、`PERIOD_LOCKED`、`INVALID_RELATIONSHIP_SCOPE`、`INVALID_ALLOCATION_CONFIG`、`INSUFFICIENT_BALANCE`、`IDEMPOTENCY_REPLAY`。

本契约只完成 DEV-001 的接口边界，不代表端点已经实现。端点实现由 DEV-003–DEV-011 按依赖接入，并使用合成数据验证。
