# REQ-015｜账户归集、报表展示与角色切换

来源：用户2026-09-16直接提供的文字及两项确认，无外部音频或页面读取。

## 用户原文

- **财务账户与报表规则**
  - **账户余额管理规则**
    - 余额统一归集要求：同一用户手机号名下的所有平台账户余额需统一合并，避免出现主账号余额为负、子账号有余额的不一致问题。
    - 明细权限隔离规则：不同登录账号仅可查看自身权限范围内的账户收支明细，无权限跨账号查看其他主体的账户数据。
  - **收入汇总表展示规则**
    - 零值项自动隐藏规则：收入汇总表中对应收入项金额为 0 时，无需在用户界面展示，仅展示有实际发生额的收入条目。
    - 非角色项自动隐藏规则：非当前用户所属角色对应的收入项，无需向用户展示，用户仅可见自身被分配角色对应的收入内容。
- **角色权限与系统架构**
  - **角色权限管理机制**
    - 角色分配规则：用户初始注册仅为普通账号，所有特殊角色均由联盟管理员统一划拨分配，用户无自主获取特殊角色的通道。
    - 角色切换实现方案：采用同一账号登录后右上角切换角色的方式，切换后自动跳转至所选角色对应的专属功能页面。

## 两项边界确认

1. 问：同一手机号统一余额，是否只合并该用户本人的各角色/个人账户余额，校区等独立公司账户仍单独核算、不并入个人余额？
   答：“仅合并本人余额，公司账户独立（推荐）”。
2. 问：你提到的“主账号、子账号”，是否就是同一手机号登录后的不同角色页面，共用一次登录；不同人的登录账号继续各自独立？
   答：“是，同一登录下切换角色（推荐）”。
