# REQ-019｜分配比例最高权限与岗位查看范围

来源：2026-09-17当前任务用户明确修正。产品正文见[PRODUCT](../../PRODUCT.md)，执行证据见[PROJECT_LOG](../../PROJECT_LOG.md)。

## 用户原文

> 运营校长不可调整分配比例，分配比例为最高权限，只能由管理员修改，校长，分区财务，场地运营，教研组长都只能看到自己的分配比例

## 明确规则与覆盖关系

- 所有比例、默认值及分配规则写入只允许管理员；其他岗位没有可调整部分，不预留负责人可调额度。本次覆盖REQ-017/REQ-018保留的负责人可调设想，关闭D28。
- 运营校长、分区财务、场地运营、教研组长只查看本人当前职责对应比例，不查看下属成员、其他岗位比例或完整分配表。管理名单、人员安排及查看营收不改变此限制。
- 收入归属及组织结构不变，校区对应比例仍服务于校区独立收入，不改成校长个人收入；分区自身分润与各校区营收汇总仍分列。工资仍仅总部财务/管理员视角维护，个人页不展示。
- 其他未列岗位的比例查看范围沿用已有授权，本次不据四岗位限制另行扩大或重设；所有非管理员的比例修改权限均明确禁止。

## 实现解释与验收

- “自己的比例”是本人该职责实际对应的分配项，不是来源教师全部绩效配置。例如组长在关联费用中只取得组长份额，不能展开该教师的导师、场地、财务等其他份额。
- 兼任通过当前职责上下文控制：切换到相应职责查看自己的那部分，兼任管理员仍需切到管理员视角进行全量配置。
- 服务器过滤名单、报表、历史配置、详情和嵌套分配对象；不把全量比例发给客户端后仅隐藏。错误响应和复制配置接口也遵循同一权限。
- 所有非管理员直接写比例、逐笔Q、基础费率、档位、上限、批量默认或表8配置均被拒；管理员允许按原数值/比例校验保存并留痕。管理员完整备份保留全部配置及历史，不因岗位查看限制裁剪。
- 本次是字段查看及配置权限变化，不改变系统内部完整分配计算、收入统计或已授权分区内人员安排。
