# REQ-023｜自有场地免收费、受邀提现与校区归属

来源：2026-09-18用户对REQ-022解释的三项修正。当前契约见[PRODUCT](../../PRODUCT.md)，执行见[PROJECT_LOG](../../PROJECT_LOG.md)。REQ-022原文作为历史保留，本文件明确覆盖关系。

## 用户原文

> -使用自己的场地仍计算5%，进入自己的独立场地账户，不默认免收，用自己的场地不收取任何费用
> -场地的发起者可以设定受邀老师的提现权限
> -学业规划产出的给校区的百分二归属于学业规划自身所在校区

## 已确认规则

1. 使用授课老师本人场地时，不收场地费用；不向个人扣场地豆、不向场地账户增加对应收入。其他授课分配照常；他人场地默认5%和管理员比例配置权保留。
2. 场地发起者可设置受邀老师对该场地的提现权限，覆盖“受邀人一律不能提现”。查看权不自动等于提现权；获权老师仅可提该场地可用余额，不能合并个人或其他场地资金。
3. 学业规划介绍产生的校区2%，给介绍方学业规划自身所在校区账户，覆盖D33未定。规划师8%与导师2%的内部拆分，不将校区管理费改给其导师校区；导师本人介绍沿规划招生分支取其本人校区。

## 衔接解释与验收

- 自用依据授课老师与实际场地所有者是同一自然人，不按推荐人或提现申请人判断；获邀提现不改变场地所有权，不能借此免除他用费用。自用仍需真实场地和所有者记录。
- 场地修改仍从当周起。F=1000、他用5%时场地50；改自用后原场地−50、授课老师个人+50，更早周不变。自用改他用则个人−50、新场地+50。不重复增加F或全额分配。其他项目费率及舍入前精确份额不变；沿既定统一尾差算法到分后，个别类别可能有0.01豆差额，所有受影响账户一并记实际差额。
- 查看与提现逐场地、逐人授权并记录授予/撤销；受邀人不因此获得改比例、改所有权或转授权权限。提交时校验当前有效提现权、对应账户余额，保留申请人、来源账户和授权证据。
- 沿用提交足额即扣豆并通过、收款姓名银行卡必填且提交后不可改撤、财务线下转账的流程。撤销受邀提现权阻止新的提交，不自动撤销已成功提交的申请；财务撤回返还原场地账户。提现授权不赋予账务人工调整权限。
- 保存该笔有效介绍方校区关系，不拿最新校区覆盖历史；调校区生效粒度仍归D32。校区2%管理费归属与授课方校区的分配前F总营收分别统计。
- D33关闭；D35仅保留共享字段及可选场地目录范围。D30/D32/D34/D35/D36仍待决定。本轮只更新文档，未开发或接入真实账务。
