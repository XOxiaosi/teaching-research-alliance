# REQ-026｜开发前边界确认

日期：2026-09-20。来源：本任务开发规划期间的用户文字答复。

## P01 分区结算读取

问题：分区财务能否查看辖区教师的个人结算？原始需求允许，后续整理出现冲突；工资和他人分配比例仍遵守已确认的限制。

用户答复：“仅查看个人余额与收入汇总”。

## D32 关系变更生效

问题：调校区、换教学指导导师等尚未确定的关系变更，以及寒假中途变更，应如何确定生效范围？组长、场地、规划导师的普通周变更规则保持已确认口径。

用户答复：“由管理员逐次指定生效范围并预览影响”。

## D35 场地目录

问题：授课老师选择授课场地时，应能选择哪些场地？这与共享看板的查看、提现权限分开设置。

用户答复：“可选择全部正常使用中的场地”。
