## 录音一：课时费结算规则讨论

1. 净课时费 = 本人接收产生的课时费减去总额，该回答正确。
2. 参与净课时费计算的流水：所有有填数据的流水都计入，不分任何状态（不设待接收、已拒绝、作废流水）。
3. 金额最多保留两位小数，同意。
4. 金额精度与分尾差处理，同意。
5. 分润比例不可能超过100%（课时费参数 = 100%减其他），若超过即报错，该条不记录计算。
6. 分润角色未指定收款人：报错，该条数据不记录计算。
7. 主子结算补齐收款人按A结算；所属校区的分润给到B（独立校区账户）。
8. 同一人兼任多个分润身份：金额累加，但需按不同身份分列显示（如导师收入、教研组组长收入分开）；账号分类与角色定位隔离——账号只分个人/公司，角色分老师、公司管理层、系统管理员三类。
9. 欢乐豆 = 1元结算，所有与钱相关的项目统一用欢乐豆表达。
10. 取消当前费率，同意。
11. 基础费率调整区间和最终上限修改后实时生效；规则性修改作用于整个财年，已结算历史保持可溯源，整年度费率全部重新计算。
12. 每周课时费由接收老师每周填写实际费用，财务不需确认，直接进入计算环节。
13. 跨月周归属：录入时锁定，由系统管理员手动指定结算月份；年初提前制定全年计划；寒暑假单独标定，一整个暑假/寒假各相当于一周。
14. 无拒收环节；推送学生3周内未被接收则系统默认删除（留存记录并备注未接收成功），再次推送可激活该记录，推送人也可自行删除。
15. 结算时间：有新数据进入即实时结算；每周填写完毕实时计算费率，动态费率按月累加、实时更新，到档后整月按该档费率计算。
16. 补录/差错：缺在哪就补在哪；各字段/阶段设截止时间，默认每周二晚12点截止录入，节假日和寒暑假管理员可手动调整截止时间，但结算始终实时进行。
17. 工资、实项奖金、医社保及实项扣费全部按月记录。
18. 余额跨月结转：余额实时结算并始终保留，除非提现或统一扣款。
19. 月度总结建议个人显示，同意。
20. 普通用户提现时，申请人和支付账户只能是本人，全部采纳。
21. 已完成时入账，按建议执行。
22. 单据拒绝、撤销、修改：单据可撤回、可退回修改，同意。
23. 允许余额为负值，但只有正的余额才能提现；提现流程：平台提交申请 → 财务审批通过 → 用户端扣款 → 财务单独把钱结算给用户。
24. 线下支付：所有交易在线下进行，与线上系统无关；首版只记录线下支付结果；提现时老师自行提交银行卡信息（开户行、姓名、账户）。
