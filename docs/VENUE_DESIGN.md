# 场地创建、共享授权与独立看板

依据 [PRODUCT F02](../PRODUCT.md#f02教师资料账户与归属表1)。进度由[开发日志](../product-log/PROJECT_LOG.md)维护；本文定义下一工作包接口，不表示已实现。

## 账户与权限

场地创建由教师本人发起，在一个事务内建立场地、唯一VENUE结算账户、零余额和创建记录。个人账户与每一个场地账户独立。同名不合并；幂等重试返回同一场地。

场地所有者可维护名称、可用状态、本人默认场地，以及该场地受邀教师的VIEW/WITHDRAW权限。两种权限分别保存，均不代表可以改场地、改费率或继续授权他人。只持WITHDRAW者使用现有场地提现入口，不因此取得使用明细看板；只持VIEW者不能提交提现。

受邀人须为有效教师，所有者隐含拥有两种权限且不向自己重复发出邀请。撤权关闭当前授权历史，不删除已发生收入或已提交提现；同一时点的并发变更须用版本阻止互相覆盖。

场地停用后不再供新授课选择，原账户、使用记录、权限历史和已存在债权保留；不阻断既有合法余额的提现。停用默认场地同时清除默认标记。改默认只影响后续明确使用默认的选择，不改写已有学生或费用。

## 服务边界

- 写服务负责创建、改名、启停、默认与权限更新，所有请求记录操作者、版本、时间、前后值及幂等键。服务端以场地所有权校验管理能力，不能仅凭传入所有者ID授权。
- 读服务返回本人所有场地及有效VIEW共享场地；使用看板包含教师、独立学生/课程、业务周、有效场地费、退款/变更影响和该场地成员权限。
- 看板按所选当前财年期间统计使用费，累计可提现余额独立显示。提现不会减少使用费收入统计；自用费用保留实际使用记录并显示0。
- 明细以每笔费用最新有效分配中的场地项、业务期场地关系为准，排除已批准退款的有效收入；不把教学课时费总额当作场地收入。
- 场地余额仅向所有者及已获提现授权者按既有账户读取规则提供。共享看板不泄露所有者个人余额、工资、银行卡或其他岗位比例。

本包复用venue、venue_permission_grant、settlement_account和现有提现服务，不建立第二套场地钱包。授课场地修改引起当周分配重算属于另一个有依赖的工作包，不能仅改场地字段而跳过差额结算。

## 验收

验证多场地账户隔离、创建与默认并发、非所有者无法维护或转授、VIEW/WITHDRAW独立、撤权阻止新提现而不撤旧申请、停用保留历史和余额、自用0与他用场地费、退款不重复扣统计，以及服务端字段隔离。
