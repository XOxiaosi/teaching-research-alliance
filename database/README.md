# 数据库迁移

迁移文件按数字前缀顺序执行，目标数据库为 PostgreSQL。首个迁移只建立身份、账户、组织、职责和审计的基础表；费用、分配和不可变账本在 DEV-003–DEV-006 中追加，不在首个迁移里预先制造不完整的业务表。

本地开发只允许使用合成数据。可使用 Docker Desktop 启动隔离的 PostgreSQL 容器执行迁移和数据库门禁；不得连接真实业务数据库。`0004_ledger.sql`建立不可变事件/分录、余额投影和幂等载荷摘要字段；账本事件与分录禁止更新和删除，余额投影由事务服务维护。每次新环境仍应从空库按数字顺序执行全部迁移，并记录迁移、约束和恢复验证证据。

当前本地验证使用 `postgres:16-alpine` 合成容器，映射到 `localhost:55432`，数据库名为 `teaching_research_alliance`。API 连接池通过 `DATABASE_URL` 注入连接字符串，账本适配器的真实发布与幂等重放已在该库验证。容器名和启动方式只服务于本地开发，不作为生产部署配置。
