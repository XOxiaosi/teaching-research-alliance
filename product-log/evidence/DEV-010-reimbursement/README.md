# DEV-010 网页普通报销申请与人工审核证据

对应PRODUCT F08/F13：个人提交普通报销申请，总部财务人工批准或驳回，管理员/开发者仅管理读取。APPROVED明确为审核通过、待划拨，不提供实际划拨/原单重开/批准后作废按钮。教师周费用仍首项，新增入口置后。

## 前端范围

个人三身份使用REIMBURSEMENT草稿，填写正数金额、原因并选择业务单据及申请截图的精确已就绪版本。提交仅待审核，申请和审核均不改变余额及收入概览。详情显示原金额、申请人、审核原因和时间，原件保留可下载。

未知创建、提交或审核结果保留原请求及幂等键，审核决定与原因同时冻结；跨页面保留、阻止切换身份和退出。状态冲突清旧输入并重新读取，不生成新请求自动重试。成功事实与后续读取失败分开，权限失效按既有父级流程清理会话。
